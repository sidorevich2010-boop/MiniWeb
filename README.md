# Personal Notes — Telegram Mini App

Веб-версия заметок для запуска внутри Telegram на iPhone, Android и компьютере. В проекте нет сервера и токена бота. Файлы `index.html`, `style.css`, `app.js`, `assets/`, `.nojekyll` и `.github/` нужно разместить **в корне отдельного репозитория**.

## Публикация с Windows через GitHub

1. Создайте **отдельный** репозиторий на [github.com/new](https://github.com/new). Назовите, например, `personal-notes-mini`. Для GitHub Pages на бесплатном тарифе выберите **Public**. Не публикуйте в репозитории свои личные JSON-копии заметок.
2. Распакуйте архив, откройте папку `PersonalNotes-Telegram` и через **Add file → Upload files** загрузите её **содержимое**, включая папку `.github`. На GitHub должен открываться `index.html` прямо в корне.
3. На странице репозитория откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**.
4. Откройте **Actions → Publish Telegram Mini App**. Дождитесь зелёной галочки. Адрес получится вида `https://ВАШ-ЛОГИН.github.io/personal-notes-mini/`. Проверьте, что заметки открываются по нему в браузере.
5. В Telegram откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`, задайте имя и свободное имя пользователя, заканчивающееся на `bot`. Бот выдаст токен; **не добавляйте токен в GitHub** — приложению он не нужен.
6. В @BotFather отправьте `/setmenubutton`, выберите своего бота, укажите HTTPS-адрес из шага 4 и текст кнопки `Заметки`. После этого откройте чат с ботом и нажмите кнопку меню.
7. При желании в BotFather → **Bot Settings → Configure Mini App** задайте тот же адрес как Main Mini App. Тогда на профиле бота появится кнопка запуска.

Публикация доступна любому, кто знает URL, но заметки лежат в локальном хранилище браузера пользователя, не в репозитории. Заходить лучше через своего бота в личном чате.

## Функции и данные

- Папки и заметки, текст и списки. В папке заметки показаны компактными карточками с небольшим скруглением в две колонки, с последовательным чередованием колонок: заголовок выделен жирнее, несколько пунктов или строк текста показаны обычным начертанием. Создание заметки — через кнопку **«+»** рядом с шестерёнкой: выберите текстовую заметку или список. При создании заметки открывается страница редактирования: у списка можно независимо включить галочки и нумерацию, затем нажать **«Готово»**. В обычном экране заметки остаются пункты и кнопка добавления; название, переключатели и добавление в Google Календарь доступны через шестерёнку справа вверху. Выполненные пункты перемещаются вниз, Enter создаёт следующий пункт.
- Свайп папки влево открывает круглую кнопку корзины. Свайп заметки влево открывает круглые кнопки перечёркнутого глаза и корзины. На компьютере работает перетаскивание мышью или правый клик; свайп вправо закрывает действия. Скрытые заметки открываются через небольшой блок с замком над папками; количество скрытых заметок не показывается. Название папки слева, количество обычных заметок — справа.
- Чтобы поменять порядок карточек заметок или пунктов списка, удерживайте небольшую точку слева и перетащите блок к нужному соседу. Подсветка показывает вставку до или после него. У края экрана список прокручивается. После отпускания порядок сохраняется и попадает в JSON-копию. Активные и выполненные пункты упорядочиваются отдельно, галочки не меняются; порядок в других папках сохраняется.
- Высота карточек подстраивается под текст. Колонки заполняются независимо с отступом 10 пикселей: короткая заметка не оставляет под собой пустой ряд из-за высокой соседней карточки. Высота пересчитывается при изменении ширины экрана и загрузке шрифта.
- В настройках списка выберите, что делает галочка: переносит пункт в «Выполнено» или оставляет отмеченным на прежнем месте. Во втором режиме пункты можно перетаскивать независимо от их отметки. Выбор сохраняется для каждой заметки и в веб-копии JSON; у старых заметок по умолчанию включён перенос в «Выполнено». Окно выбора типа новой заметки закрывается крестиком справа вверху.
- Шестизначный локальный код скрытых заметок; смена в настройках. Код защищает доступ в интерфейсе, **содержимое заметок не шифруется**. При очистке хранилища код и заметки пропадут.
- Даты создания и изменения мелким текстом у нижнего края экрана заметки, тёмная тема. Блок фото и голосовых убран из интерфейса; ранее сохранённые вложения сохраняются в резервных копиях.
- Экспорт и импорт JSON формата 1 из Android/iOS версий. При импорте вся текущая база заменяется, поэтому сначала экспортируйте её. Копия JSON содержит данные без шифрования; храните её безопасно.
- Резервные копии с прежними голосовыми `.webm` могут быть восстановлены в веб-версии, но текущие нативные Android/iOS версии принимают только `.m4a`.
- Кнопка Google Календаря открывает форму создания события с названием и текстом заметки. Это не автоматическая двусторонняя синхронизация.

Хранилище — IndexedDB внутри браузера Telegram **на данном устройстве**. Telegram CloudStorage и Google Drive в этой версии не подключены. Между iPhone и Android данные не появляются автоматически: используйте экспорт/импорт JSON. Если Telegram очищает данные сайта или удаляется, без копии заметки восстановить нельзя. Код и заметки не отправляются боту.

## Технически

Шрифт интерфейса — Manrope с кириллицей, свободная версия из [Google Fonts](https://github.com/google/fonts/tree/main/ofl/manrope). Он включён в проект локально, без обращения к Google Fonts при открытии приложения. Лицензия SIL Open Font License 1.1 находится в `assets/fonts/OFL-Manrope.txt`. Основной текст — вес 400, названия — 550–600.

Статический HTML/CSS/JavaScript без сборки и внешних зависимостей, кроме официального скрипта Telegram WebApp. HTTPS предоставляет GitHub Pages. Архив `assets/icon.png` используется как иконка страницы. У приложения нет backend и нет проверяемой сервером авторизации Telegram; ник пользователя из `initDataUnsafe` намеренно не используется как доказательство личности. Для настоящей облачной синхронизации понадобится backend с проверкой подписи `initData`, ограничением доступа по Telegram ID и защищённым хранением вложений.
